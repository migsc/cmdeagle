01 · One spec, three surfaces
Write it once.
It speaks to everyone.

        
Every cmdeagle tool comes from one versioned cmdeagle.yaml. From it, cmdeagle builds a terminal UI for people, a JSON contract for programs, and a skill file that teaches your agent to use the tool.

      

      

        

          
cmdeagle.yaml


schemaVersion: 2
name: backup
description: Copy a folder somewhere safe, without surprises.

args:
  - name: source
    type: path
    mustExist: true

flags:
  to:    { type: path, required: true }
  prune: { type: boolean, describe: Remove files gone from source }

effects:
  reads:  [source]
  writes: [to]
  destructive: { when: prune }
dryRun: required

run: ./scripts/backup.sh

        

        

          

            
            $ backup ~/Projects --to /mnt/vault --dry-run
            

              
              
              
            

          

          

        

      

      

        
Human
A terminal UI built on Ink: help that teaches, a live preview of the plan, and errors that say what to do next.

        
Machine
Versioned JSON results, diagnostics on stderr, and exit codes that don't change. No colors or spinners in a pipe, ever.

        
Model
A generated SKILL.md for Claude Code and other agents. It covers when to use the tool, how to call it, and what's safe.

      

    

  


  

    

      

        
02 · Side effects, declared
Your agent knows what
a command will touch.

        
Every command declares what it reads, writes, sends, and destroys. If a command changes anything, it must support a dry run, and the generated skill tells your agent to show you the plan first.

      

      

        
reads
Looks, doesn't touch.
Safe to run while exploring. Inputs are validated before your script sees them.

        
writes
Changes are previewed.
Requires --dry-run. The plan comes back as a readable preview or as JSON.

        
network
Calls out, openly.
Hosts are declared in the spec, so permission rules can allow or block them.

        
destructive
Asks before it's gone.
Can be conditional, like when: prune. The skill tells the agent to get your OK first.

      

      

        

          
dist/backup/SKILL.md · generated


## Safety
- Writes to --to. Destructive only with --prune.
- Always run with --dry-run --json first
  and show the user the plan.
- Ask before using --prune.

## Exit codes
0 ok · 2 invalid input · 3 source missing · 10 partial

03 · The loop
Your agent writes the spec.
cmdeagle checks its work.

        
cmdeagle runs as a skill inside the agent you already use. Each build returns a result your agent can read. When something fails, the error comes with a fix, and the loop keeps going until the build passes.

      

      

        
Describe
Point your agent at a script or explain the job in a sentence.
› make backup.sh a real CLI,
  safe by default

        
Spec
The agent writes cmdeagle.yaml: commands, flags, side effects. You can review it like any other file.
+ cmdeagle.yaml
+ scripts/backup.sh

        
Finalize
cmdeagle validates the spec and builds the tool. Each failure comes back with a stable code and a fix.
✗ E_FLAG_UNDECLARED $PRUNE
  hint: add flags.prune
✓ valid · built

        
Ship
You get a standalone binary and its skill file. No model, API key, or network needed to run it.

  backup
  SKILL.md
