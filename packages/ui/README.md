# @cmdeagle/ui (empty on purpose)

Reusable terminal components, harvested from the examples. A component moves
here once a **second** example needs it. See the table in
[`examples/README.md`](../../examples/README.md#shared-components).

Every component renders the same data three ways: an Ink view on a TTY,
plain text in a pipe, and the data itself for `--json`.
